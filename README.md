# Meu Gabarito ENEM

Cartão-resposta digital para conferir as alternativas do 1º dia do ENEM 2026, Prova Branca.

## Como usar

Abra `index.html` no navegador. Escolha Inglês ou Espanhol, marque as alternativas e acompanhe o total de acertos. As respostas são salvas localmente no navegador.

## Publicar na Vercel

Este projeto é estático e não precisa de etapa de build. Importe o repositório na Vercel e mantenha as configurações de build e saída vazias; a Vercel servirá o `index.html` diretamente. O arquivo `vercel.json` já está incluído.

## Observação

O gabarito foi transcrito da imagem extraoficial compartilhada na conversa e deve ser conferido com uma fonte oficial quando disponível.
